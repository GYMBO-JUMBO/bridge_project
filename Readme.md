This project demonstrates the Bridge design pattern in Java.

The project is based on Resident Evil characters and weapons.

## Structure

- `Character` - abstraction
- `JillValentine` and `AdaWong` - refined abstractions
- `Weapon` - implementor
- `Pistol` and `Shotgun` - concrete implementors
- `Main` - demonstrates how characters can use different weapons

## How it works

The Bridge pattern separates characters from weapon implementations.

This allows different characters to use different weapons without changing the character classes.

For example:

Jill Valentine can use a Shotgun or Pistol.

Ada Wong can also use a Shotgun or Pistol.
